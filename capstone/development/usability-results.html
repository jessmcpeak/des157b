Usability Test Results

Jess L McPeak

Key Insights

  • The experience seems to function properly, but seems to be severely lacking content.
  • The use of colorful text is helpful for telling characters apart.
  • The formatting differences between spoken dialogue and action text is useful and clear.
  • Possibility of looking at stage play scripts as reference for text formatting.
  • Being able to immediately skip to the "end" without doing the desired tasks (no apparent checks system) is disorienting and breaks immersion.
  • Choices seemed dynamic based on where you were ("who is [blank]" choices change based on scene)

Next Steps

  • Fill out text content.
  • Add imagery.
  • Look into implementing checks system.
  • Fix technical issues.
